每个示例占据的 slot

surface.main认领视图
surface.canvas全局视图
panel.sidebar跟随主区
panel.canvas跟随画布

三条必须演出来的差别

  1. 一切皆 App：导航与视图都由 App 贡献
  2. Agent 是通道：在界面里干活
  3. 多舞台并行：主区 / 画布 / 面板同时活
建议首发 Morningside —— 纯读接口，最容易做出「第一屏就有内容」的反差截图；第二个做 Butler（ava-app 已有设计），把「常驻智能体」的叙事立起来。
